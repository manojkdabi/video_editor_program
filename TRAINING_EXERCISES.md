## Exercise 1: First Video Creation (Beginner)

**Objective:** Create your first simple video

**Time:** 20 minutes

**Skills Practiced:**
- Launching application
- Importing video files
- Saving projects
- Exporting videos

### Materials Needed
- 2-3 short video clips (any content, 10-30 seconds each)

### Step-by-Step Instructions

1. **Launch the Application**
   - Double-click `run_editor.bat`
   - Wait for window to open

2. **Start New Project**
   - Click "New Project" button
   - Timeline should be empty

3. **Import Videos**
   - Click "Import Video"
   - Select 2-3 video files
   - Click "Open"

4. **Verify Timeline**
   - Check videos appear in "VIDEO CLIPS:" section
   - Note the order (they'll play in this order)

5. **Save Project**
   - Click "Save Project"
   - Name it: "Exercise_1_First_Video"
   - Choose location: Documents\VideoProjects
   - Click "Save"

6. **Export Video**
   - Click "Export Video" (green button)
   - Quality: Medium
   - Format: MP4
   - Name: "My_First_Video"
   - Location: Documents\ExportedVideos
   - Click "Save"
   - Wait for export to complete

7. **Watch Result**
   - Navigate to Documents\ExportedVideos
   - Double-click "My_First_Video.mp4"
   - Watch your creation!

### Success Criteria
✓ Application launched successfully
✓ Videos imported and visible in timeline
✓ Project saved with correct name
✓ Video exported successfully
✓ Final video plays correctly

### Reflection Questions
1. How long did the export take?
2. What file size is the exported video?
3. Does the quality look good?

## Exercise 2: Mixed Media Project (Intermediate)

**Objective:** Create a video using multiple media types

**Time:** 30 minutes

**Skills Practiced:**
- Importing different media types
- Understanding timeline structure
- Working with images and audio
- Quality comparison

### Materials Needed
- 2 video clips
- 2-3 images (JPG or PNG)
- 1 audio file (MP3 - could be music or narration)

### Instructions

1. **Launch and Create New Project**

2. **Import Media in This Order:**
   - First: Import your 2 videos
   - Second: Import your 2-3 images
   - Third: Import your audio file

3. **Review Timeline Structure**
   - Should see three sections:
     - VIDEO CLIPS: (your videos)
     - IMAGE CLIPS: (your images, each 5.0s)
     - AUDIO CLIPS: (your audio)

4. **Calculate Expected Duration**
   - Video 1: _____ seconds
   - Video 2: _____ seconds
   - Image 1: 5 seconds
   - Image 2: 5 seconds
   - Image 3: 5 seconds (if applicable)
   - Total visual: _____ seconds
   - Audio: _____ seconds

5. **Save Project**
   - Name: "Exercise_2_Mixed_Media"

6. **Export First Version**
   - Quality: Low
   - Name: "Exercise2_Low"
   - Note: File size and export time

7. **Export Second Version**
   - Quality: High
   - Name: "Exercise2_High"
   - Note: File size and export time

8. **Compare Results**
   - Play both videos
   - Compare quality
   - Compare file sizes

### Success Criteria
✓ All media types imported
✓ Timeline shows all three sections
✓ Both exports completed
✓ Can compare Low vs High quality

### Analysis
Fill in this table:

| Version | Export Time | File Size | Quality Rating (1-10) |
|---------|-------------|-----------|----------------------|
| Low     |             |           |                      |
| High    |             |           |                      |

### Reflection Questions
1. Is the quality difference noticeable?
2. Is the file size difference significant?
3. Which quality would you use for most projects?

## Exercise 3: Product Training Video (Advanced)

**Objective:** Create a realistic Insoil product training video

**Time:** 45-60 minutes

**Skills Practiced:**
- Content planning
- Media organization
- Professional workflow
- Quality assessment

### Scenario
Create a 3-5 minute training video about the Insoil soil testing device (or any product/process you have materials for).

### Materials Needed
- 1 intro/welcome video (15-30 seconds)
- 2-3 demonstration videos (30-60 seconds each)
- 2-3 product photos or diagrams
- 1 closing video (15-30 seconds)
- 1 narration audio file (optional but recommended)

### Part 1: Planning (10 minutes)

**Create a Video Plan:**

```
Section 1: Introduction
- Clip: intro_welcome.mp4 (20s)
- Purpose: Welcome viewers

Section 2: Overview
- Clip: product_image.jpg (5s)
- Purpose: Show the device

Section 3: Demonstration
- Clip: demo_part1.mp4 (45s)
- Clip: demo_part2.mp4 (45s)
- Clip: demo_part3.mp4 (30s)
- Purpose: Show how to use device

Section 4: Key Features
- Clip: feature_diagram.jpg (5s)
- Purpose: Highlight important features

Section 5: Conclusion
- Clip: closing.mp4 (20s)
- Purpose: Thank viewers

Estimated Total: 2:50
```

### Part 2: Execution (20 minutes)

1. **Organize Files First**
   - Create folder: RawMedia\Exercise3
   - Copy all needed files there
   - Rename files clearly:
     - 01_intro.mp4
     - 02_product_image.jpg
     - 03_demo_part1.mp4
     - etc.

2. **Launch Application**

3. **Import in Order**
   - Import videos in the sequence you planned
   - Import images in the sequence you planned
   - Import audio if you have it

4. **Verify Timeline Matches Plan**
   - Check order is correct
   - Verify all files are present

5. **Save Project**
   - Name: "Exercise_3_Product_Training"
   - Save frequently during work!

### Part 3: Export and Review (15 minutes)

1. **First Export (Draft)**
   - Quality: Medium
   - Name: "Exercise3_Draft"
   - Purpose: Quick review

2. **Watch and Take Notes**
   - Does order make sense?
   - Is anything missing?
   - Are images long enough to read?
   - Does audio sync well?

3. **Make Adjustments** (if needed)
   - Re-import in different order if necessary
   - Save project again

4. **Final Export**
   - Quality: High
   - Name: "Exercise3_Final_Product_Training"
   - This is your deliverable!

### Part 4: Quality Check (10 minutes)

**Review Checklist:**
- [ ] Video starts with clear introduction
- [ ] Content flows logically
- [ ] Images are shown long enough to understand
- [ ] Audio is clear (if included)
- [ ] Video ends with clear conclusion
- [ ] Total length is 3-5 minutes
- [ ] Export quality is High (1080p)
- [ ] File plays without issues

### Success Criteria
✓ Complete planning document created
✓ All media organized before import
✓ Timeline matches planned structure
✓ Draft reviewed and notes taken
✓ Final version exported at High quality
✓ Quality checklist completed
✓ Video is professional and useful

### Deliverables
1. Video plan document (can be handwritten notes)
2. Organized media folder
3. Saved project file (.vedproj)
4. Draft video (Medium quality)
5. Final video (High quality)

### Reflection Questions
1. How long did the entire process take?
2. What would you do differently next time?
3. What was the most challenging part?
4. Is the final video ready to share with others?

## Exercise 4: Efficiency Challenge (Intermediate)

**Objective:** Create a video as quickly as possible

**Time:** 15 minutes (target)

**Skills Practiced:**
- Speed and efficiency
- Workflow optimization
- Decision-making under time pressure

### Challenge
Create a complete video in 15 minutes or less:
- Must include at least 3 video clips
- Must include at least 1 image
- Must be saved as project
- Must be exported (Medium quality)

### Rules
- Set a timer for 15 minutes
- Start timer when you launch application
- Stop timer when export completes
- All media must be prepared before starting timer

### Preparation (Before Starting Timer)
1. Gather 3 videos and 1 image
2. Put them in one folder
3. Decide on order
4. Have export location ready

### The Challenge
1. Start timer
2. Launch application
3. Import all media (fastest method)
4. Verify timeline
5. Save project quickly
6. Export (Medium quality)
7. Stop timer when export done

### Scoring
- Under 10 minutes: Expert! ⭐⭐⭐
- 10-15 minutes: Great! ⭐⭐
- 15-20 minutes: Good! ⭐
- Over 20 minutes: Need more practice

### Tips for Speed
- Organize files first
- Use Ctrl+Click to select multiple files at once
- Have project name ready
- Use default settings when possible
- Don't overthink - just do it!

### Success Criteria
✓ All media imported
✓ Project saved
✓ Video exported successfully
✓ Completed in under 15 minutes

## Exercise 5: Troubleshooting Practice (All Levels)

**Objective:** Learn to solve common problems

**Time:** 20 minutes

**Skills Practiced:**
- Problem diagnosis
- Using documentation
- Self-sufficiency

### Simulated Problems

**Problem 1: Missing File**
1. Create a project with 2-3 videos
2. Save the project
3. Close the application
4. Move one of the video files to a different location
5. Reopen the application and load the project
6. **Challenge:** What error do you get? How do you fix it?

**Problem 2: Export Failure**
1. Create a simple project
2. Try to export to C:\Windows\
3. **Challenge:** What happens? Why? Where should you export instead?

**Problem 3: Can't Find Exported Video**
1. Export a video but don't pay attention to where you save it
2. **Challenge:** How do you find it?

### Solutions Check
Compare your solutions with `TROUBLESHOOTING_GUIDE.md`

### Success Criteria
✓ Identified all three problems
✓ Found solutions independently or with documentation
✓ Applied fixes successfully

## Exercise 6: Real-World Project (Advanced)

**Objective:** Complete a real project from start to finish

**Time:** 2-3 hours

**Skills Practiced:**
- Everything learned so far
- Professional workflow
- Project management

### Assignment
Create a real training video for your organization:
- 5-10 minutes long
- Professional quality
- Ready to share with audience

### Full Workflow

**Phase 1: Pre-Production (30-45 minutes)**
1. Write a script (what will you say/show?)
2. Identify all needed media
3. Record/gather all video clips
4. Record/gather all audio
5. Prepare all images
6. Create organized folder structure

**Phase 2: Organization (15 minutes)**
1. Create project folder
2. Organize all media files
3. Rename files clearly
4. Create detailed plan document

**Phase 3: Editing (30-45 minutes)**
1. Launch video editor
2. Import all media in planned order
3. Verify timeline
4. Save project (multiple times!)
5. Export draft (Medium quality)
6. Review draft

**Phase 4: Refinement (20-30 minutes)**
1. Make notes on improvements
2. Make any necessary changes
3. Save project again
4. Export final version (High quality)

**Phase 5: Delivery (10 minutes)**
1. Watch final version completely
2. Verify quality acceptable
3. Check file size reasonable
4. Move to delivery location
5. Create backup copy

### Deliverables
1. Written script
2. Organized media folder
3. Project plan document
4. Saved project file
5. Draft video
6. Final video (High quality)
7. Project notes/lessons learned

### Success Criteria
✓ Complete professional video created
✓ All documentation completed
✓ Video meets quality standards
✓ Ready to share with audience
✓ Workflow documented for next time
