# Video Tutorial Script

Script for creating video tutorials about the Video Editor application.

## Tutorial Series Overview

This script is designed for creating a series of video tutorials that teach users how to install and use the Video Editor. Each tutorial is designed to be 3-10 minutes long.

## Tutorial 4: Working with Projects (4 minutes)

### Opening (15 seconds)
**Narrator:**
"Welcome to Tutorial 4! Today we're learning about project management - how to save, load, and organize your work effectively."

---

### Section 1: Understanding Projects (1 minute)
**[Screen: Show .vedproj file icon]**

**Narrator:**
"When you save a project, the Video Editor creates a .vedproj file. This file is small - just a few kilobytes - because it doesn't contain your actual videos. Instead, it contains:
- A list of which files you imported
- The order of your clips
- Your export settings

Think of it like a recipe card - it tells the Video Editor what ingredients to use and in what order."

---

### Section 2: Saving Best Practices (1 minute)
**[Screen: Demonstrate saving]**

**Narrator:**
"Here are important rules for saving projects:

First, save early and often. Click 'Save Project' after importing media, and every 5-10 minutes while working.

Second, use descriptive names. Instead of 'Project1', use names like 'Training_Video_Part1' or 'Product_Demo_January'.

Third, keep all your project files in one folder. I keep mine in Documents\VideoProjects."

---

### Section 3: Loading Projects (1 minute)
**[Screen: Demonstrate loading]**

**Narrator:**
"To continue working on a saved project, click 'Load Project'. Navigate to your .vedproj file and click Open. The Video Editor loads all your clips exactly as you left them.

One critical point: DO NOT move or rename your original media files after importing them. The project remembers where the files are located. If you move them, the Video Editor won't be able to find them."

---

### Section 4: File Organization (45 seconds)
**[Screen: Show folder structure]**

**Narrator:**
"Here's a recommended folder structure:

Create a 'VideoProjects' folder for all your .vedproj files.
Create a 'RawMedia' folder with subfolders for Videos, Images, and Audio.
Create an 'ExportedVideos' folder for your final videos.

This organization keeps everything tidy and makes files easy to find."

---

### Closing (15 seconds)
**Narrator:**
"Good project management makes editing easier and prevents lost work. Remember: save often, use clear names, and keep files organized.

Next time, we'll explore export quality settings and when to use each one. See you then!"

## Tutorial 5: Export Quality & Settings (6 minutes)

### Opening (20 seconds)
**Narrator:**
"Welcome to Tutorial 5! Choosing the right export quality is important for balancing video quality against file size. Let's learn when to use each setting."

---

### Section 1: Understanding Quality Presets (2 minutes)
**[Screen: Properties panel showing quality options]**

**Narrator:**
"The Video Editor offers three quality presets: High, Medium, and Low. Let's see what each means.

**[Screen: Show comparison table]**

High quality exports at 1920x1080 - that's Full HD. It produces the best quality but larger file sizes. For a 5-minute video, expect about 300 megabytes.

Medium quality exports at 1280x720 - regular HD. This is the sweet spot for most projects - good quality at reasonable file sizes. A 5-minute video is about 150 megabytes.

Low quality exports at 854x480 - standard definition. Use this for quick previews or when file size is critical. A 5-minute video is about 75 megabytes."

---

### Section 2: When to Use Each Quality (2 minutes)
**[Screen: Split screen examples]**

**Narrator:**
"Use High quality when:
- Creating final professional videos
- Uploading to YouTube or Vimeo
- Archiving important content
- Quality is more important than file size

Use Medium quality when:
- Sharing videos online
- Most training videos
- Emailing to colleagues (if not too large)
- You need a good balance

Use Low quality when:
- Creating quick draft previews
- File size must be small for email
- Testing your project before final export
- Video will only be viewed on mobile devices

For 90% of your projects, Medium is the right choice."

---

### Section 3: Format Selection (1 minute)
**[Screen: Format dropdown]**

**Narrator:**
"You can also choose output format: MP4, AVI, or MOV.

MP4 is the best choice for almost everything. It works on all devices, has good compression, and wide compatibility.

AVI produces the highest quality but very large files. Only use this for archival or further editing.

MOV is Apple's format - works better on Macs. Use only if specifically requested.

For Windows users creating training videos, always use MP4."

---

## Production Notes

### Recording These Tutorials

**Equipment Needed:**
- Screen recording software (OBS Studio, Camtasia, or similar)
- Good microphone for clear narration
- Video editing software (ironically, you can use the Video Editor itself!)
- Sample media files for demonstrations

**Recording Tips:**
1. Record in 1920x1080 resolution
2. Use a clean, distraction-free desktop
3. Slow down mouse movements for clarity
4. Pause briefly between steps
5. Record in sections, not all at once
6. Leave gaps for editing

**Narration Tips:**
1. Speak slowly and clearly
2. Use a friendly, encouraging tone
3. Avoid technical jargon
4. Repeat important points
5. Sound enthusiastic but not over-excited
6. Practice the script before recording

**Post-Production:**
1. Remove long pauses and mistakes
2. Add zoom effects for important UI elements
3. Add arrows or highlights to draw attention
4. Include text overlays for key points
5. Add background music (soft, non-distracting)
6. Export at High quality

### Tutorial Length Guidelines

- Keep each tutorial under 10 minutes
- 5-7 minutes is ideal
- Break complex topics into multiple short videos
- Always start with overview, end with summary

### Accessibility

- Provide closed captions for all tutorials
- Speak clearly for non-native speakers
- Show on-screen text for important points
- Use high contrast for visibility
